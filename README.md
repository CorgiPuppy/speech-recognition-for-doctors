# Инструкция по установке и запуску Medical Voice Parser

1. Распакуйте программу:
   - Поместите файл main.exe в любую папку (например, C:\MedicalParser).

2. Установите модель Vosk:
   - Скачайте модель vosk-model-ru-0.42 с сайта: https://alphacephei.com/vosk/models
   - Распакуйте архив и поместите папку `models` рядом с файлом main.exe.
     Структура должна быть:
     C:\MedicalParser\main.exe
     C:\MedicalParser\models\vosk-model-ru-0.42\...

3. Установите Typst для создания PDF:
   - Скачайте typst.exe с сайта: https://typst.app/
   - Поместите файл typst.exe в ту же папку, где находится main.exe:
     C:\MedicalParser\typst.exe

4. Запустите программу:
   - Дважды щёлкните по main.exe.
   - Если появляется ошибка, убедитесь, что папка `models` и файл `typst.exe` находятся в правильной директории.

5. Использование:
   - Нажмите "Начать запись" и произнесите данные пациента, например:
     "Пациент Золотухин Андрей Александрович давление сто шесть на девяносто девять пульс девяносто восемь сатурация девяносто восемь процентов".
   - Нажмите "Извлечь" для заполнения полей, затем "Добавить запись".
   - Для сохранения отчётов выберите папку и используйте "Сохранить все в JSON" или "Создать PDF для всех".

6. Требования:
   - Windows (64-bit).
   - Микрофон для записи голоса.
   - Около 2 ГБ свободного места для папки `models`.
